About This App

Cyber Security Awareness App

CyberSafe is a simple app made to help people understand basic cyber security and stay safe while using the internet.

In this app, you can check suspicious messages and emails, learn about common scams, read safety tips, and take a small cyber security quiz.

Project Objective

The main aim of this project is to create awareness about cyber security. It helps users understand common online frauds, phishing messages and other cyber risks.


CyberSafe

CyberSafe is a student project based on cyber security awareness. It provides some simple tools and information to help users stay safe online.
